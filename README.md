# Actividad2-git-txt
Repositorio de práctica para el uso de comandos básicos de Git:
`add`, `commit`, `mv`, `log` y `push`.

## Archivos

- `universidad.txt`: lista de útiles de la universidad
- `pan.txt`: ingredientes para hacer pan
- `series-pendientes.txt`: series por ver
- `materias.txt`: materias del semestre

## Qué se practicó

- Crear archivos y modificarlos
- Renombrar un archivo con `git mv`
- Escribir mensajes de commit claros y descriptivos
- Subir los cambios a GitHub con `git push`
